# Session Artifacts and Traces

## Overview

This project investigates the storage I/O generated by coding-agent sessions, including tool-call operations and the framework's own session artifacts. The main objective is to understand and predict the storage I/O produced by individual agent sessions and determine when shared storage becomes a bottleneck as the number of concurrent agents increases.

## Research Questions

- **Q1:** Developing a predictive model for block-level storage I/O of coding-agent sessions using incomplete tool-call traces.
- **Q2:** Predicting the fleet size at which shared storage reaches saturation and identifying which system layer (storage device, file system, or CPU) becomes the bottleneck first.

## Project Goals

- Study existing research and identify research gaps in coding-agent storage I/O.
- Explore and characterize coding-agent sessions, tool calls, commands, and timing information.
- Develop a model to predict session-level storage I/O from tool-call traces.
- Generate representative workloads through repeatable session re-execution and I/O replay.
- Evaluate storage performance under increasing numbers of concurrent agents.
- Analyse results and validate predictions across different storage configurations.

## Project Status

Currently in the research and groundwork phase, focusing on TraceLab dataset exploration, workload characterization, and experimental planning.
